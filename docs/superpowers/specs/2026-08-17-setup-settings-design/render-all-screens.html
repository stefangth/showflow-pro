What Get running takes over
The dashboard stage chain, the module setup rails, the collapsed resume chip and the four-card explainer strip on Settings. All four exist to answer "what now", and one board answers it better. The chain's copy survives as the phase names and the unlock lines.
What must not be lost
Per-step capability gating, the admin-only markers, the scoped booking save, provenance on every rule, module-off footers, and the deep links from notifications. Each one has a home above.
Build order
Five sections first, since it is a re-grouping of routes that already exist. Then the board reading the same setup status the rails read today. Then panels, in blocking order: casts, timing, artists, letterhead, terms.

Gaps I found while checking
Artists have a second settings surface today, Profile, and it is the only one they can reach. It now follows the same row pattern as Settings rather than a separate card idiom.
Two notification categories, booking activity and at-risk, are never sent to artists. Today they render as live switches on an artist's profile. Screen 09 shows them stated and dimmed instead.
Filters visibility is a per-role setting living in Preferences. It moved next to Roles and rights, where the same question is already being answered.
